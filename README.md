# 🚀 My Terminal Developer Toolkit

Welcome to my custom-built developer workspace sandbox! This repository tracks my journey from learning the basic terminal command-line prompt to building fully automated system scripts and visual desktop applications using **Zsh/Bash with Python**.

All core tool scripts are safely managed inside a hidden repository vault (`~/.scripts/`) to keep my main operating system completely spotless.

---

## 🎨 System Configurations & Theme
My workspace environment utilizes a retro **Homebrew Amber Terminal Profile** paired with custom shorthand shell commands designed to automate daily workflows.

Every time I launch a new Terminal window, my Mac automatically initializes my paths and greets me out loud using text-to-speech technology!

## 🕹️ Command Controller Suite Reference

I engineered a complete suite of one-letter shortcut **aliases** configured directly inside my `~/.zprofile`. I can trigger complex system tasks instantly with a single keystroke:

### 🖥️ Graphical User Interface (GUI) Desktop Apps
* `v` ➡️ **Secure Password Vault:** Launches a desktop application window that generates secure passwords and automatically injects them directly onto my macOS clipboard (`pbcopy`).
* `m` ➡️ **Visual Grid Calculator:** Deploys an interactive grid-button math engine mimicking native operating system application interfaces.
* `g` ➡️ **GUI Click Counter:** My very first visual Tkinter application window tracking event-driven button clicks.

### ⚙️ Automation & Analytics Tools
* `c` ➡️ **Downloads Folder Cleaner:** A smart, conflict-protected sorting program that loops through my messy downloads directory and cleanly organizes files into folders (*Images, Documents, Videos, Code*, etc.).
* `i` ➡️ **Mac Core Shell Report:** A pure Zsh native shell script (`.sh`) bypassing macOS privacy layers to generate a live diagnostic of my system date, user account, and local network partitions.
* `l` ➡️ **System Status Logger:** Collects live hard drive storage values, active RAM partitions, and uptime stats, compiling them into a permanent text file report.
* `r` ➡️ **Text File Reader:** A terminal-based analytics utility that opens text documents on screen and calculates word counts, character lengths, and line densities.

### 🎮 Performance & Recreation
* `d` ➡️ **Live System Performance Dashboard (`btop`):** Launches a graphical text monitor mapping my live CPU usage, hardware temperatures, and core battery metrics.
* `s` ➡️ **Retro Snake Game (`nsnake`):** Launches an interactive, keyboard-controlled terminal game of Snake to enjoy between coding sessions.
